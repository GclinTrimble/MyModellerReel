# MyModellerReel 0.27.0: survey field book, OGC web maps, civil-first copilot

## Fix field mistakes in a survey

A Trimble JobXML job now comes in with its **field book**: station setups, backsights, rod, instrument and antenna heights, prism constants, GNSS bases, every observation, notes and photos. Fix a wrong rod or instrument height in the office and every point it touched moves, with the surface and linework built on them.

![Fix a rod height](https://github.com/GclinTrimble/MyModellerReel/releases/download/v0.27.0/edit-survey-measurements.gif)

- **Field book** panel (Survey tab): **Check the survey** flags runs of shots at another rod height, backsight residuals, odd prism constants, poor GNSS precision and duplicate names; **Fix** on each finding, editable cells, bulk rod height, **As measured** and **Undo all edits**.
- Points move by exactly what the edit changes on top of the controller's own result; untouched points stay as stored.
- Export the survey to LandXML (Survey section, both ways), OGC InfraGML Part 6, and an HTML survey report.
- Fixed: points re-measured after a deleted shot were dropped on import.
- Commands: `list_survey`, `review_survey`, `edit_survey_observations`, `compare_survey`, `recompute_survey`, `survey_report`.

## Web map and feature layers (OGC)

Aerial imagery, cadastre, zoning or utilities under the model from any OGC service, streamed around the view in the project coordinate system.

![Map layers](https://github.com/GclinTrimble/MyModellerReel/releases/download/v0.27.0/web-map-layers.gif)

- WMTS, WMS 1.3, OGC API - Tiles and XYZ map layers; WFS 2.0 and OGC API - Features (CQL2 filters) feature layers you can style, filter, query ("which parcels does the road cross") and bring into the model.
- Layer sets saved as OWS Context, styles as SLD / SE, features to and from GeoPackage.
- **Take this area offline** caches the tiles and features around the view.
- Saved services and layer sets follow your account; API keys stay in Windows Credential Manager.
- Coordinate engine reads WKT-CRS 2 and reproduces Trimble's grid coordinates to 0.1 mm.
- What is implemented per standard, and the test that covers it: [docs/standards/ogc.md](https://github.com/GclinTrimble/MyModellerReel/blob/main/docs/standards/ogc.md).

## A copilot for civil and survey work

- Plumb's instructions now speak civil engineering and surveying: project coordinates, chainages, grades and batters, sensible precision, never inventing survey data. Each request carries the site summary (CRS, points, surfaces, alignments, corridors).
- New skills: road design, drainage and utilities, earthworks; the survey skill checks field books.
- AIs build in the app with commands, not by writing files to import: `create_feature_library`, `add_points`, `import_schedule` with tasks.

## Component library

- Ctrl-click no longer makes the Library panel jump; Shift-click picks a run of tiles.
- Animated machine GLBs from other tools (rigs with pivot notes) import assembled instead of falling apart.

## Known limits

- WMTS layers draw in Web Mercator only; WFS needs GeoJSON output.
- Map layers ignore datum shifts and geoid grids (about a metre on some national datums).
- The InfraGML export is not validated against the schema yet.

## Install

Download `MyModellerReel-Setup-0.27.0.exe` and run it; installed copies update themselves.
